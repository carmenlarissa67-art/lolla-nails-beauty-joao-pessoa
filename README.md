# Lolla Nails & Beauty | João Pessoa

Demo: https://lolla-nails-beauty-joao-pessoa.vercel.app

Site com agendamento (Calendly + WhatsApp) da Lolla Nails & Beauty, Techne Mall Brisamar.

- Toda a personalização fica em `src/data/studioData.js` (equipe, catálogo, horários, WhatsApp, Calendly).
- `npm run dev` para rodar local, `npm run build` para a Vercel.
- `npm run build:html` gera um arquivo único (`dist/index.html`) que abre offline, para enviar por WhatsApp.
